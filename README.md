# Blog App

Blog App adalah aplikasi blog sederhana yang dibuat menggunakan Laravel dan Bootstrap untuk tampilan antarmuka. Aplikasi ini memungkinkan pengguna untuk membaca dan mengelola artikel.

## Prasyarat

Sebelum memulai, pastikan Anda memiliki hal berikut:

- PHP 8.3 atau lebih tinggi
- Composer
- Node.js dan NPM
- MySQL atau database lain yang didukung Laravel
